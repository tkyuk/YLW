그룹박스

입력 => 조회조건 이름 삭제

시트가 마스터일 경우 입력이 조회조건이므로 이런 경우에는 유지

조회 => 조회조건 컬럼명 유지

시트가 마스터인 경우

- 마스터 부분에 키 값 필요 없음

- 행삭제가 삭제이므로 삭제 툴바 필요 없음

체크 SP 주의 사항

- 기본적인 순서가 정해져있음 => 필수 입력체크, 데이터 유무 체크가 맨 앞에 나온다

- 업무별 외부키가 필요없으면 번호생성 밑에 부분 필요 없다

(번호생성시 이니셜이 사업부문일 경우 해당 사업부문의 이니셜을 가져오고, 사업부문 아닐경우는 0으로 넣어줌)

저장, 삭제 메소드 => 비즈니스 아래부터 트랜잭션 필수

단가정보입력

저장,삭제 부분은 금지표시(트랜잭션) 비즈니스 부터 아래로 다걸어준다

이화면은 시트가 마스터성 데이터이기 때문에, 전체삭제 필요없다
