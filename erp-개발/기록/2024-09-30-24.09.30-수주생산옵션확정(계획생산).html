24.09.30 수주생산옵션확정(계획생산)

수주생산옵션확정(계획생산) 화면에서 옵션 확정 시 작업지시가 생성 되는데

수량이 상이하게 생성 되는 것 같습니다.

디버깅 요청합니다.

출처: \<http://61.250.183.6:8100/Page/Open/69355/100101/0/18820244>

--SELECT * FROM _TPDSFCWorkOrder WHERE WorkOrderSeq IN (3477,3478,3479)

--SELECT * FROM _TPDSFCWorkReport WHERE WorkOrderSeq IN (3477,3478,3479)

DECLARE @CompanySeq INT = 1

,@OrderSeq INT = 102381

SELECT Qty, * FROM _TSLOrderItem WHERE OrderSeq = 102381

-- 1. 수주품목구분 = 제품 (구동기 무) / OEM반제품

SELECT CASE WHEN B.UMOrderType IN (1000846001, 1000846012) AND B.DriverSeq = 0 THEN 1 -- 수주품목구분 = 제품 (구동기 무) / OEM반제품

WHEN B.UMOrderType IN (1000846001, 1000846012) AND B.DriverSeq \<> 0 THEN 2 -- 수주품목구분 = 제품 (구동기 유) / OEM반제품

WHEN B.UMOrderType = 1000846003 THEN 3 -- 수주품목구분 = 가공품

WHEN B.UMOrderType = 1000846005 THEN 4 -- 수주품목구분 = 보수품

WHEN B.UMOrderType = 1000846011 THEN 5 -- 수주품목구분 = OEM제품 (구동기 무)

WHEN B.UMOrderType = 1000846010 THEN 6 -- 수주품목구분 = OEM제품 (구동기 유)

END

FROM _TSLOrderItem AS A WITH(NOLOCK)

JOIN ssv_TSLOrderItem AS B WITH(NOLOCK) ON B.CompanySeq = A.CompanySeq

AND B.OrderSeq = A.OrderSeq

AND B.OrderSerl = A.OrderSerl

JOIN _TSLOrder AS C WITH(NOLOCK) ON C.CompanySeq = A.CompanySeq

AND C.OrderSeq = A.OrderSeq

JOIN ssv_TSLOrder AS D WITH(NOLOCK) ON D.CompanySeq = C.CompanySeq

AND D.OrderSeq = C.OrderSeq

WHERE A.CompanySeq = @CompanySeq

AND A.OrderSeq = @OrderSeq

-- 수량, 생산처는 생산의뢰 기준으로 처리

SELECT A.Qty,

B.UMProdCust

FROM _TPDMPSProdReqItem AS A

JOIN ssv_TPDMPSProdReqItem AS B ON B.CompanySeq = A.CompanySeq

AND B.ProdReqSeq = A.ProdReqSeq

AND B.Serl = A.Serl

WHERE A.CompanySeq = @CompanySeq

AND A.ProdReqSeq = 100639

--AND A.Serl = @ProdReqSerl

SELECT Z2.Qty

,A.Qty,A.OrderSerl

FROM _TPDMPSProdReq AS Z1 WITH(NOLOCK)

JOIN _TPDMPSProdReqItem AS Z2 WITH(NOLOCK) ON Z2.CompanySeq = Z1.CompanySeq

AND Z2.ProdReqSeq = Z1.ProdReqSeq

JOIN ssv_TPDMPSProdReqItem AS Z3 WITH(NOLOCK) ON Z3.CompanySeq = Z2.CompanySeq

AND Z3.ProdReqSeq = Z2.ProdReqSeq

AND Z3.Serl = Z2.Serl

JOIN ssv_TSLOrderNo AS Z WITH(NOLOCK) ON Z.CompanySeq = Z3.CompanySeq

AND Z.OrderSeq = Z3.OrderSeq

AND Z.OrderSerl = Z3.OrderSerl

LEFT OUTER JOIN _TSLOrderItem AS A WITH(NOLOCK) ON A.CompanySeq = Z3.CompanySeq

AND A.OrderSeq = Z3.OrderSeq

AND A.OrderSerl = Z3.OrderSerl

LEFT OUTER JOIN _TSLOrder AS B WITH(NOLOCK) ON B.CompanySeq = A.CompanySeq

AND B.OrderSeq = A.OrderSeq

WHERE Z1.ProdReqSeq = 100639

AND A.OrderSerl IN (8,9,10)

[수주생산옵션확정(계획생산)_ssv] 화면을 통해 생성된 건의 경우

수주품목구분 = 제품 (구동기 무) / OEM반제품 인 건으로,

해당 건의 경우 수량, 생산처는 생산의뢰 기준으로 처리되도록 구성되어있습니다.

확인 부탁 드립니다.
