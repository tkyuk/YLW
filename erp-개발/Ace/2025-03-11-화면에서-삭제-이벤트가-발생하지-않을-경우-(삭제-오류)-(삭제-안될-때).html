화면에서 삭제 이벤트가 발생하지 않을 경우 (삭제 오류) (삭제 안될 때)

문제 상황

화면에서 툴바의 삭제 버튼을 클릭할 때 삭제 이벤트가 실행되지 않는 경우

해결 방안

삭제 이벤트가 중복되어 충돌이 발생하는 경우

폼 메인에 삭제 이벤트가 있으면 버튼이나 기타 다른 MethodType을 '처리'로 설정합니다.

삭제 이벤트가 하나인데도 작동하지 않는 경우

주로 점프 후 발생하는 경우가 많습니다. 점프 후 조회 할 때 _base.IsOpen이 true가 아닌 false로 되어있는 경우입니다.

원인은 마스터에는 아무런 액션이 취해지지 않고 시트에만 조회했기 때문에 발생됩니다. 

이 경우에는 아래의 두가지 처리를 해 줍니다.

조회 한 다음 마스터에도 처리결과 반영

조회 성공 후 _base.IsOpen = true 로 변경
