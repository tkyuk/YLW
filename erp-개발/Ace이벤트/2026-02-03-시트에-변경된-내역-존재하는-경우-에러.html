시트에 변경된 내역 존재하는 경우 에러

-- 시트에 저장되지 않은 데이터가 있는 경우 저장 후 처리하도록 메세지

for row = 0, SS9.DataRowCnt - 1 do

SS9.ActiveRow = row

if SS9.WorkingTag == 'A' or SS9.WorkingTag == 'U' then

msg = '저장 후 출고 확정/취소 가능합니다.'

MessageBox(msg, '', 'MsgBoxTypeOK')

GoTo('END')

return

end

end
