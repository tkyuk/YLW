Unable to load file

오류 수정 요청

1. 수출 LC입력, 수출 INVOICE 입력, 수출면장입력, 수출 BL입력, 수출NEGO입력 등 각 화면에서 에러메세지가 뜨면서 제대로 데이터가 보이지 않습니다.

에러메세지는 아래와 같습니다.

수출 LC입력 : Unable to load file "Yls.Sales.SELCDB"

수출 INVOICE 입력 : Unable to load file "Yls.Sales.SEInvoiceDB"

수출면장입력 : Unable to load file "Yls.Sales.SEPermitDB"

수출 BL입력 : Unable to load file "Yls.Sales.SEBLDB"

수출NEGO입력: Unable to load file "Yls.Sales.SENegoDB"

2. 해당 오류 수정 요청드립니다.
