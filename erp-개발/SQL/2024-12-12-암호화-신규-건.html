암호화 신규 건

예시

테이블 컬럼 암호화 되는 과정

제뉴인 : _TCOMEncryptInfo

ACE : _TWCOMEncryptInfo

이 테이블에 테이블명과 해당테이블의 컬럼이 등록되어있어야 해당 테이블에 해당컬럼이 저장될때

암호화되서 저장된다.

이미 값이 있는 테이블을 나중에 암호화 하려면

1. 해당 테이블에 테이블과 컬럼을 인서트 해주고

EX)

sys_TDACustDivisionStoreHist

sys_TDACustDivision

sys_TDACustAddDivision

sys_TDACustBankAccDivision

sys_TDACustEmpInfoDivision

sys_TDACustTaxHistDivision

insert _TCOMEncryptInfo

select 1 CompanySeq, 197 Seq, '_TDABankAcc' TableName, 'BankAccNo' ColumnName, 1 LastUserSeq, getdate() LastDateTime

union select 1 CompanySeq, 198 Seq, '_TDACustBankAcc' TableName, 'BankAccNo' ColumnName, 1 LastUserSeq, getdate() LastDateTime

2. 암호화시킬 컬럼 길이를 바꿔준다. 너무 짧으면 오류난다.

EX)

alter table _TDABankAcc alter column BankAccNo nvarchar(400) not null

alter table _TDACustBankAcc alter column BankAccNo nvarchar(400) not null

3.테이블에 해당컬럼만 전체 업데이트하면 암호화되서 업데이트됨

EX)

UPDATE _TDABankAcc

SET BankAccNo = dbo._FCOMEncrypt(B.BankAccNo, '_TDABankAcc', 'BankAccNo', 1)

from _TDABankAcc B

UPDATE _TDACustBankAcc

SET BankAccNo = dbo._FCOMEncrypt(B.BankAccNo, '_TDACustBankAcc', 'BankAccNo', 1)

from _TDACustBankAcc B

암호화 된 컬럼은 복호화해야 정상 조회 가능

ex) dbo._FCOMDecrypt(KE.AccNo, '_THRBasEmpAccNo', 'AccNo', @CompanySeq)
