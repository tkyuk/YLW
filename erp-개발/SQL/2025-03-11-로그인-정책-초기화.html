로그인 정책 초기화

로그인 정책 초기화

문제 상황

관리자 등의 사용자가 로그인할 수 없을 때

해결방안

DB에서 아래와 같이 업데이트 합니다.

UPDATE _TCAUser 

SET LoginPwd        = '',           -- 해시암호인경우

LoginStatus     = 18003,        -- 임시사용

PwdChgDate      = convert(varchar, getdate(),112),  -- 암호변경일을 초기화

LoginFailCnt    = 0,            -- 로그인실패횟수 초기화

LoginFailFirstTime = Null       -- 최근 실패건수 초기화

FROM _TCAUser

WHERE UserID = 'UserID'

해시암호인 경우 기존 암호를 잠시 보관하고 '5690dddfa28ae085d23518a035707282'  로 업데이트합니다.    이때 암호는 a1234567 입니다.
