# 고정셀 해제

고정셀 해제

**1. 틀 고정 해제 단축키 (순서대로 누르세요)**

엑셀은 Alt 키를 누르면 상단 리본 메뉴에 가이드 문자가 뜹니다. 아래 순서대로 키보드를 하나씩 누르시면 됩니다.

- **Alt → W → F → F**

> **상세 순서:**

1.  **Alt**: 리본 메뉴 활성화

2.  **W**: '보기(Vie**w**)' 탭 선택

3.  **F**: '틀 고정(**F**reeze Panes)' 메뉴 선택

4.  **F**: '틀 고정 취소(**F**reeze Panes)' 실행
