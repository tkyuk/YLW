# Editor 3.0

title - 반복되지 않는 부분

data - 반복되는 부분

 

header, footer가 있고 그 안에 데이터가 있는 느낌

 

RD는 데이터베이스에 직접 접속한다

Title =\> 제목

데이터헤더 =\> 컬럼명

파란줄 = 데이터가 아래로 계속 쌓인다는걸 의미

검은줄 = 중복이 안됨 (그냥 하나만 나옴)

(왼쪽)빨간줄 = 선 굵기 조절

 

크기 조절 : 우클릭 - 개체크기맞춤

드래그해서 크기 조절하면 에러가 생길 수도 있음

(Ctrl Z 가 한번 밖에 안됨)
