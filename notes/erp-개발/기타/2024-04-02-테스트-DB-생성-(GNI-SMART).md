# 테스트 DB 생성 (GNI SMART)

+. DB 삭제

\- 레지스트리 삭제

\- DB 분리 / 이동 / DB에서 새로 고침 후 문제 발생 없으면 이동한 파일 삭제

\- DB 분리 : 우클릭 - 테스크 - 분리 (오래걸림)

\- 그냥 삭제 : 우클릭 삭제 - 최하단 체크박스 2개 체크

 

 

2\. G&I Smart (3번 인증키 작업이 없다)

\- 1. DB 생성 이름 : DB명 + 날짜 OR DB명 + test

\- 1-1. 레지스트리에 DB에 대한 커넥션 설정

\- 2. 생성되는 DB는 1개 (Common이 없으니까) / 예외적으로 정산 sys분리가 필요할 때에는 DB명_netra+test 추가로 복원

\- 2-1. netra 추가 복원 시 NETRA APP 추가 설치 필요 (app - netra는 일대일 관계 이기 때문)

\- +. 4. 출력물을 같이 봐야할 때에는 ODBC 설정까지 같이 진행해야 함 (보통은 잘안함 / 출력물을 보려면 설정해야한다 / 출력물을 새로 만드는건 아님)
