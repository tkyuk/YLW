# 사용자정의코드

\<\<사용자정의, 시스템제공 코드.hwp\>\>

 

> 프로그램등록
>
> 1\. 사용자정의코드분류등록(영림원AS) \_TDAUMajor
>
> 2\. 시스템제공코드분류값등록 \_TDASMajor
>
>  
>
> \* 사용자 정의코드 (\_TDAUMinor)
>
> 쓰는 이유 : 사용자를 위해 만든 코드를 정리한 곳
>
> ![](assets/사용자정의코드/image17.png)
>
>  
>

>
>  
>
> \_TDAUMajor - 대분류 코드 (ex.수주구분)
>
> \_TDAUMinor - 소분류 코드
