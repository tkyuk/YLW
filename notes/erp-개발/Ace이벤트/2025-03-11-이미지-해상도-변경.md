# 이미지 해상도 변경

**해상도 변경**

 

**개요**

이미지 컨트롤에서 이미지의 해상도를 변경하는 방법을 설명한 문서입니다.

 

**설명**

**기능 설명**

이미지 컨트롤에서 이미지의 해상도를 변경하기위해서는 아래 방법을 사용하여 변경할 수 있습니다.

이미지 컨트롤에서 이미지의 기본 저장 사이즈는 400\*400 입니다.

이 size를 변경하려면 init()함수에 아래와 같이 코드를 추가 합니다. 

1

2

imageControl.ThumbWidth = 1024

imageControl.ThumbHeight = 788

 

조정된 값은 이미지 컨트롤.TextCd 값으로 저장되며 데이터 수집시 자동으로 수집됩니다.

 

 

 

작은 크기의 이미지를 따로 저장할 경우

주로 시트에서 작은 이미지를 출력 할 때 이미지의 크기에 따라서 출력속도의 차이가 크게 발생합니다.

이런 경우 DB의 Table에 원본 이미지와 축소 이미지를 위한 두개의 컬럼을 생성합니다.

원본 이미지 컬럼에는 imageControl.TextCd값을 저장하고 축소 이미지 컬럼에는 imageControl.TextThumbSmail 을 저장합니다.

원본 이미지는 데이터 수집으로 자동 수집이 되며 축소 이미지는 아래의 코드를 사용하여 수집된 데이터셋에 추가합니다.

TextThumbSmail 의 기본 크기는 50\*40으로 되어 있으며 변경하려면 init()함수에 아래와 같이 코드를 추가합니다.

1

2

imageControl.ThumbSmallWidth = 100

imageControl.ThumbSmallHeight= 100
