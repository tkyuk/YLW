# 컨트롤 정렬

**개요**

컨트롤의 스타일 속성인 정렬 기능 사용법에 대해 설명한 문서입니다.

 

 

**설명**

루아 스크립트를 통해 스타일 속성을 변경할 수 있습니다.

 

 

**정렬 기능 사용법**

 

**제공하는 스타일 속성**

<span class="mark">H_CaptionAlignment -\> 캡션</span>을 정렬합니다.

 

<span class="mark">H_ContentAlignment -\> input</span> 값을 정렬합니다.

 

 

 

값에 따른 정렬 종류

 

| 값  | 정렬   |
|-----|--------|
| 0   | Left   |
| 1   | Center |
| 2   | Right  |

 

출처: \<<https://kdc.ksystem.co.kr/developments/erpdev/M1736830306315>\>

 

 

 

 

 

**Input 정렬** 기능이 적용되는 컨트롤 : Datebox,Datetime,Floatbox,Maskbox,Multitextbox,Password,Textbox

 

**캡션 정렬** 기능이 적용되는 컨트롤 : Combobox,Datebox,Datetime,Floatbox,Maskbox,Multitextbox,Password,Textbox

 

 

 

**예시**

 

-- 캡션 가운데 정렬

컨트롤ID.H_CaptionAlignment = 1;-- input 오른쪽 정렬

컨트롤ID.H_ContentAlignment = 2;
