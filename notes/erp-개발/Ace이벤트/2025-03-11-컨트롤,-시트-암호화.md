# 컨트롤, 시트 암호화

**컨트롤 암호화**

Init() 이벤트에 Lua로 설정합니다. 텍스트, 마스크, 패스워드 컨트롤에 사용합니다. 

 

 

ex. ctl.IsCodeEncryption = true

 

 

 

**시트 암호화**

Init() 이벤트에 Lua로 작성합니다.

 

SS1.ActiveColumnName = 'ResiID'

SS1.IsCodeEncryption = true -- IsCodeEncryption는 ActiveColumn의 암호화 여부를 변경합니다.
