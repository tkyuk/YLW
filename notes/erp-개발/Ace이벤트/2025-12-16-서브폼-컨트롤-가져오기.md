# 서브폼 컨트롤 가져오기

| **구성 요소** | **설명** |
|----|----|
| pgmControlName | 값을 설정할 대상 **프로그램(폼)의 ID**입니다. <sup>2</sup> |
| controlName | 값을 설정할 프로그램 내의 **Control Name**입니다. <sup>3</sup> |
| **반환 값** | 지정한 controlName에 해당하는 **컨트롤 객체**를 반환합니다. |

 

-- Lua Script -- pgmID는 AddPgmUserControl 등으로 서브폼을 추가할 때 받은 프로그램 ID 변수입니다.

-- 서브폼(pgmID) 내의 'fltQCSeq' 컨트롤에 -- 메인 폼의 'fltQCSeq' 컨트롤이 가진 'Value' 값을 설정합니다.

GetPgmUserControl(pgmID, 'fltQCSeq').Value = fltQCSeq.Value

 

> pgmID = AddPgmUserControl('GridCanvasItem',500774, false)
>
> GetPgmUserControl('FrmWPRBasEmpAmt', 'cmbPuName').Value = cmbPuName.Value
>
> GetPgmUserControl('FrmWPRBasEmpAmt', 'cmbPuName').TextCd = cmbPuName.TextCd
>
> GetPgmUserControl('FrmWPRBasEmpAmt', 'cmbPb').Value = cmbPbName.Value
>
> GetPgmUserControl('FrmWPRBasEmpAmt', 'cmbPb').TextCd = cmbPbName.TextCd

if SS1.DataRowCnt \> 0 then

> SS1.DblClickRow = 0
>
> GetPgmUserControl('FrmWPRBasEmpAmt', 'txtEmpNameQ').Value = CellText(SS1, SS1.DblClickRow, 'EmpSeq')
>
> GetPgmUserControl('FrmWPRBasEmpAmt', 'txtEmpNameQ').TextCd = CellText(SS1, SS1.DblClickRow, 'EmpSeq')

else

> GetPgmUserControl('FrmWPRBasEmpAmt', 'txtEmpNameQ').Value = 0
>
> GetPgmUserControl('FrmWPRBasEmpAmt', 'txtEmpNameQ').TextCd = 0

end
