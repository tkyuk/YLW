# 체크박스 저장

--==============================================================

-- 체크박스 저장 - 누르면 바로 저장 / 저장 안된 데이터 있으면 '저장 후 체크 메세지 출력' FrmWPDSample_djb / djb_SWPDSampleSaveCfm

--==============================================================

if SS1.WorkingTag ~= '' then

> MessageBoxShow('저장 후 처리하세요.', '')
>
> if CellText(SS1, SS1.ActiveRow, 'IsCfm') == '1' then

        SetText(SS1, SS1.ActiveRow, 'IsCfm', '0')

> elseif CellText(SS1, SS1.ActiveRow, 'IsCfm') == '0' then
>
> SetText(SS1, SS1.ActiveRow, 'IsCfm', '1')
>
> end
>
> GoTo('END')
>
> return

end

IsCfm - Sel로 ControlKey 설정

 

G - Active Row

 

M
