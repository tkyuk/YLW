# 컨트롤키 모음

컨트롤키 모음(Control Key)

기본 Control Key

| 종류 | 설명 |
|----|----|
| HID | 컨트롤에 HID속성을 추가하여 숨길 수 있음 |
| SHID | 컨트롤에 SHID속성을 추가하여 숨길 수 있음 (칼럼의 경우 컨트롤과 다르게 숨긴 칼럼보기에서도 숨겨짐) |
| LCK | 컨트롤 잠금 |
| DIS | DIS 속성을 추가하여 값 입력 비활성화 할 수 있음 |
| NON | 필수 조건 체크 컨트롤 |
| NOQ | 빨간색 글씨로 표현되며 조회하기 위한 필수조건 체크 컨트롤 |
| NOS | 빨간색 글씨로 표현되며 저장하기 위한 필수조건 체크 컨트롤 |
| QRY | 주로 조회조건 컨트롤에 사용되며 해당 컨트롤이 변경되더라도 조회, 저장, 삭제 시 변경여부 체크로직에 걸리지 않음 |
| YMD | 날짜 컨트롤의 기본값을 설정 |
| TOT | 시트에서 합계 지원모드로 사용됨 |
| SUM | 시트에서 합계 지원모드로 사용됨 |
| AVG | 시트에서 평균값을 구하기 위해 사용할 수 있음 |
| MAX | 시트에서 최댓값을 구하기 위해 사용할 수 있음 |
| MIN | 시트에서 최솟값을 구하기 위해 사용할 수 있음 |
| SEL | 시트에서 SEL 속성이 등록된 칼럼은 입력하거나 체크로 변경해도 WorkingTag가 변경되지 않음 |
| CLC | 코드도움 컨트롤 Text를 지울때 Link컨트롤의 값을 모두 지움 |
| ICH | 코드도움 설정 시 Link 컨트롤에 값을 설정하지 않음 |
| ISC | CLC와 같이 사용하며 타 코드도움 컨트롤에 Link 된 컨트롤의 경우 코드도움 관련 값을 설정하지 않음 |
| SCH | 시트에서 코드도움 시 Multi-Select를 지원할지에 대한 속성 |
| RDS | 읽기 권한만 존재할 경우 DIS 처리 |
| RHD | 읽기 권한만 존재할 경우 HID 처리 |
| DATAADD | 시트 추가조회 속성 |
| KEY | 시트 추가조회 시 데이터 중복체크를 위한 값 |
| AMT | 금액권한 중에 금액읽기권한, 쓰기권한 적용 |
| COST | 금액권한 중에 비용읽기권한, 쓰기권한 적용 (단가로 활용가능) |
| DELAY | GridVisible 같은 속성을 사용하여 영역을 숨겨할 경우(ex.화면 권한) Grid Control에 DELAY 속성을 주어 숨길 수 있음 |
| FromControl | 날짜 컨트롤에서 FromControl을 추가하여 날짜 오류 체크가 가능함 |
| ToControl | 날짜 컨트롤에서 ToControl을 추가하여 날짜 오류 체크가 가능함 |

| 종류 | 설명 |
|----|----|
| PWD | 개인정보보호에 사용되며 입력과 출력 데이터 모두 암호화 |
| PWDS | 개인정보보호에 사용되며 출력 데이터만 암호화 (방패 아이콘을 클릭하여 데이터 확인 가능) |
| SCL | GridItem 컨트롤에 SCL 속성을 추가하여 화면에 스크롤을 추가할 수 있음 ( 가로/세로 스크롤 하나만 생성은 불가능) |
| HDIS | 탭 헤더를 DIS 처리하는 속성 |
| NOMSG | 파일 컨트롤에 저장시 “툴바의 '저장' 버튼을 눌러야 업로드 된 파일이 저장됩니다.” 메시지를 나오지 않게 함 |
| EXEXCEL | 대용량 파일을 엑셀로 내보내기할 경우 성능 개선을 위해 사용되는 속성 |
| QEXCEL | 대용량 파일을 엑셀로 내보내기할 경우 성능 개선을 위해 사용되는 속성 (툴바에 추가됨) |
| SKIPCLR | ClearForm 실행 시 Clear를 하지 않고 제외함 |
| TMP | 웹 파일 컨트롤 연말정산 PDF 처리 시 TEMP 폴더에 업로드 할 때 사용되는 속성 |
| RMRKHID | 웹 파일 컨트롤 실행 시 비고 버튼을 제외함 |
| VIEW | 코드도움 미리보기 |
| FROMTO | FromTo 달력을 사용하기 위해 추가된 속성 DateBox 컨트롤에 추가 후 Lua로 짝 지정해주어 사용 ( 009 버전부터 지원) |

| 종류 | 설명 |
|----|----|
| ED_BTN | 날짜 컨트롤을 버튼형 날짜 컨트롤로 변경 |
| ET_PMONTH | 텍스트 컨트롤을 기간 월컨트롤로 변경 |
| ET_PDAY | 텍스트 컨트롤을 기간 일컨트롤로 변경 |
| ET_PIDAY | 텍스트 컨트롤을 기간별 단위 일컨트롤로 변경 |
| ET_Scheduler | 텍스트 컨트롤을 스케줄러컨트롤로 변경 |
| EO_CHECK | 옵션컨트롤을 체크리스트로 변경 |
| THUMBNAILURL | 서버에 썸네일 이미지 파일이 생성되면서 이미지를 URL로 표현해 줌 (CS에서 사용불가, 웹에서만 사용가능) - EMP : 업무로 구분할 수 있는 구분자로 실제 이미지 파일이 만들어질 때 실제 파일경로로 사용 (중복되지 않게 사용) - 100 : 가로 pixel을 의미하며, 세로크기는 원본 이미지의 가로세로 비율로 처리 (30~300 크기 지원) |
| THUMBNAIL | 원본 Base64를 설정된 규격(표준사이즈100)에 맞춘 썸네일 Base64로 변경 후 DB에 저장 썸네일의 Base64가 꼭 필요한 경우가 아니라면 TUMBNAILURL사용 권장 |
| PREVPDF | ERP결재 건별 PDF 미리보기 |
