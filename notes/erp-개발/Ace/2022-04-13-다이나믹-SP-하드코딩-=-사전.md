# 다이나믹 SP 하드코딩 =\> 사전

0413

 

- 하드코딩 (mcnk_SWMRPProdPlanMatItemPreStkQueryTEST)

'투입예정' AS TitleName2

'입고예정' AS TitleName2

'과부족' AS TitleName2

- 사전 사용 (mcnk_SWMRPProdPlanMatItemPreStkQuery)

- DECLARE 부분 추가

> @Word_Input NVARCHAR(30), -- 투입예정
>
> @Word_In NVARCHAR(30), -- 입고예정
>
> @Word_Over NVARCHAR(30) -- 과부족
>
>  

- 바로 밑에 실행문 추가

> EXEC dbo.\_SWCOMGetDictionary @LanguageSeq, 15000319 , @Word_Input OUTPUT -- 구매납품
>
> IF @Word_Input IS NULL SELECT @Word_Input = N'투입예정'
>
> EXEC dbo.\_SWCOMGetDictionary @LanguageSeq, 32310 , @Word_In OUTPUT -- 입고예정
>
> IF @Word_In IS NULL SELECT @Word_In = N'입고예정'
>
> EXEC dbo.\_SWCOMGetDictionary @LanguageSeq, 25595 , @Word_Over OUTPUT --과부족
>
> IF @Word_Over IS NULL SELECT @Word_Over = N'과부족'
