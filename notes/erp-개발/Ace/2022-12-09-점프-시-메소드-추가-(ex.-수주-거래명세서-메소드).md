# 점프 시 메소드 추가 (ex. 수주 -\> 거래명세서 메소드)

![](assets/점프-시-메소드-추가-(ex.-수주-거래명세서-메소드)/image109.png)

수주, 출하 등 점프해서 거래명세서 입력으로 들어올 때,

바로 행추가 누르면 포커스가 없어서 오류 메세지 생성

=\> 포커스 해주는 이벤트 추가

 

-- 22.12.09 점프 후 바로 행추가 시 에러 제거하기 위해 포커스 설정

if SS1.DataRowCnt \> 0 then

> SetFocus(SS1)
>
> SetActiveCell(SS1, 0, 'ItemName')
>
> -- 포커스만 이동하고 이동시 ActiveRow 는 처리가 되지 않아 아래처럼 코딩 추가
>
> SS1.ActiveRow = 0
>
> SS1.ActiveColumnName = 'ItemName'
>
> -- 관리항목 시트로 In 하는 순간부터 아래로 아래로 이동하도록 처리
>
> SS1.IsEditEnterMode = true

end
