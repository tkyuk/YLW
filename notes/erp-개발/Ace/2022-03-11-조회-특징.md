# 조회 특징

사람A - 스테이플러 주문

사람B - 노트북 주문

사람C - 마우스, 키보드, 노트북 주문

==\> 주문 3건 / 품목 4개

 

주문 1건 =\> 마스터 (컨트롤)

 

품목여러개 =\> 디테일 (시트)

-----------------------

1-N 관계

==\> 입력

 

====================

\* 조회

조회는 마스터만 보인다

(몇 개 샀는지 안보임)

 

다 보고 싶다?

\*~품목조회

==\> 디테일(시트)이 보임

 

====================

\* 입력

입력에서의 조회 =\> 최신화 느낌

(다른 사람이 수정했을수도 있기 때문에)

 

(입력에서 조회는 진짜 조회가 아니라

최신화된 데이터를 보여주는 용도이다)

 

첫 저장 시

주문번호, 주문코드가 생성된다

 

 

보통 사람들은 내부코드를 모름

Seq만 알면 복잡한 조건 필요 없이 바로 원하는 값 출력이 가능
