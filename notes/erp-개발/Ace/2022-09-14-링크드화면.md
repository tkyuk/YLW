# 링크드화면

== 링크드 화면 ==

동일한 화면에서 권한만 다르게 주어 사용하려 할때 만든다

 

CS에서

1\. <span class="mark">링크드화면그룹등록 - 영림원AS</span>

링크화면그룹명 링크화면그룹ID 모든법인적용여부

SCM반품_sdng Re_sdng                체크

 

=\> 이떄 이름이 너무 길면 안됨

 

저장후 클릭하면 우측화면에 원본화면명 원본화면 ID 입력하는 시트 보임 =\> 원본화면명 입력 후 저장

 

<span class="mark">프로그램등록</span>에서 FrmWPDOSPSCMDelvReturnListLink_sdng SCM외주반품명세서내역확인(세동조회용)\_sdng 링크드화면 으로 등록 후

 

<span class="mark">링크드화면생성_영림원AS</span> 에서 조회 -\> 생성한 링크화면 그룹명 클릭 -\> 링크화면생성ID(영문) 링크화면생성명(한글) 입력 후 더블클릭

-\> 아래에 원본화면명 원본화면ID 링크드화면명 링크드화면ID 입력하는 시트에 프로그램 등록에서 만든 링크드화면 ID입력 후 저장

 

<span class="mark">링크드화면콘트롤속성정의-영림원AS</span> 에서 링크화면그룹 설정 후 조회 -\> 화면생성단위명 글릭 링크드화면명 클릭 후

우측 시트에서 컨트롤을 코드도움으로 불러오고 수정할 수 있음
