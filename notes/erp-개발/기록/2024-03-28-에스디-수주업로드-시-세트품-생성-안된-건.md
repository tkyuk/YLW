# 에스디 - 수주업로드 시 세트품 생성 안된 건

저장 SP \_SWSLOrderUploadSave 에서

 

FROM \#BIZ_OUT_DataBlock1 AS A

JOIN \_TDAItemUnit AS B WITH(NOLOCK) ON ( B.CompanySeq = @CompanySeq AND A.ItemSeq = B.ItemSeq AND A.ItemSeq = B.ItemSeq AND A.UnitSeq = B.UnitSeq )

WHERE A.WorkingTag = 'A'

AND A.Status = 0

 

\_TDAItemUnit 와 맞는 단위가 없어서 생성되지 않음

EX. EA -\> SET 로 맞는 단위 넣고 업로드 시 정상적으로 생성
