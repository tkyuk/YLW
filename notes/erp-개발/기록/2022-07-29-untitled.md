# 

※ 해당 수정내역은 엠씨넥스 베트남 테스트서버에 적용 후 회신 부탁드립니다.

테스트서버에서 테스트 후 실서버 적용할 예정입니다.

 

고정자산등록_mcnv화면에서 상단에 처분처리 버튼을 클릭하여 <span class="mark">자산처분처리</span> 팝업창을 띄운 뒤

데이터 입력, 삭제 시 \_TACAsstDispo, \_TACAsstDispoItem, \_TACAsstInOut, \_TACAsstDepreDept 테이블 뿐 아니라

mcnv_TACAsstDispoKOR, mcnv_TACAsstDispoItemKOR, mcnv_TACAsstInOutKOR, mcnv_TACAsstDepreDeptKOR 테이블에도

데이터가 저장 또는 삭제 되도록 수정요청드립니다.

 

화면 수정 없이 저장 SP만 사이트따서 진행해도 무방합니다.

참고 SP : \_SWACVNMAsstDispoSave, \_SWACVNMAsstDispoItemSave, \_SWACVNMAsstInOutSave, \_SWACVNMDepreAfDispoSave

 

 

고정자산등록_mcnv화면에서 상단에 자본적지출 버튼을 클릭하여 <span class="mark">자본적지출</span> 팝업창을 띄운 뒤

데이터 입력, 삭제 시 \_TACAsstEst, \_TACAsstInOut 테이블 뿐 아니라

mcnv_TACAsstEstKOR, mcnv_TACAsstInOutKOR 테이블에도

데이터가 저장 또는 삭제 되도록 수정요청드립니다.

 

화면 수정 없이 저장 SP만 사이트따서 진행해도 무방합니다.

참고 SP : \_SWACAsstEstSave, \_SWACAsstInOutSave
