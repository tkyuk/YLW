# 25.01.24 벌크bom처리(이젬코)

/\*

최초에 Master_IDX_No = 1665 (37건)

 

2건에 대해서 상구분을 변경 =\> 1754 (37건)

상구분 변경된 2건에 대해서는 1665가 그대로 남아있음

 

이미 BOM생성된 건에 대해서 재전송한 데이터가 수정 2건은 인터페이스유무가 NULL로 처리

 

\[벌크BOM처리(이젬코)\_gcos\] 화면에서 하위품목 조회 시 인터페이스유무가 NULL인 2건 미조회 -\> 35건

 

\[본처방세부정보조회(이젬코)\_gcos\] 에서는 인터페이스유무 NULL 2건 + Master_IDX_No = 1665 이 같이 조회되어 39건 조회

\*/

 

--=========================================================================================

--=========================================================================================

-- \[벌크BOM처리(이젬코)\_gcos\] 첫 번째 시트 조회 (마스터 조회)

-- 마스터 테이블 1건

SELECT RegDateTime,CONVERT(INT, ISNULL(A.Results,'0')),\* FROM gcos_TEGCIFLabNoBOMMaster AS A WHERE labno = '241203-009SU061227A'

 

-- \[벌크BOM처리(이젬코)\_gcos\] 두번째 시트 조회 (35건)

-- 1. MAX - Master_IDX_No 건 조회

-- 2. BOM등록여부 체크된 건의 경우 IFYn = '1' 만 조회

SELECT A.Master_IDX_No,D.Master_IDX_No,A.\*

FROM gcos_TEGCIFLabNoBOM AS A WITH(NOLOCK)

> LEFT OUTER JOIN gcos_TEGCIFLabNoBOMSub AS B WITH(NOLOCK) ON A.labno = B.labno
>
> AND A.itemcode1 = B.itemcode1
>
> AND A.childcode = B.childcode
>
> AND A.phase = B.phase
>
> AND A.subphase = B.subphase
>
> LEFT OUTER JOIN gcos_TEGCIFMatItem AS C WITH(NOLOCK) ON A.childcode = C.itemcode1
>
> OUTER APPLY (SELECT MAX(Z.Master_IDX_No) AS Master_IDX_No
>
> FROM gcos_TEGCIFLabNoBOM AS Z WITH(NOLOCK)
>
> WHERE Z.labno = A.labno) AS D
>
> WHERE A.labno LIKE '241203-009SU061227A' + '%'
>
> AND ISNULL(A.IFYn , '') = '1'

AND D.Master_IDX_No = A.Master_IDX_No

 

-- Master_IDX_No = 1754

-- Master_IDX_No = 1665 2건 존재 -\> 하위자재 조회 시 미조회됨

-- BOM 조회

SELECT LastDateTime,\* FROM \_TPDBOM WHERE ItemSeq = 36277

 

 

SELECT RegDateTime,IFDate,IFYn,\* FROM gcos_TEGCIFLabNoBOM WHERE labno = '241203-009SU061227A' ORDER BY 1

 

 

SELECT RegDateTime,IFYn,\* FROM gcos_TEGCIFLabNoBOM WHERE labno = '241203-009SU061227A' AND Master_IDX_No = 1665

 

-- BOM등록여부 체크된 건의 경우 IFYn = '1' 만 조회

SELECT IFYn,\* FROM gcos_TEGCIFLabNoBOM WHERE labno = '241203-009SU061227A' AND IFYn IS NULL

 

--=========================================================================================

--=========================================================================================

-- \[본처방세부정보조회(이젬코)\_gcos\]

 

-- 39건

SELECT

A.Results,

IFYn,

Master_IDX_No,

A.childname AS childname

, A.childcode AS childcode

, A.conqty AS conqty

, A.phase AS phase

, A.subphase AS subphase

, CASE WHEN ISNULL(A.Results,'') = '' THEN '0' ELSE '1' END AS IsIF

FROM gcos_TEGCIFLabNoBOM AS A WITH(NOLOCK)

WHERE A.labno = '241203-009SU061227A'

ORDER BY A.phase, A.childcode

 

 

-- 원료함량 집계

SELECT SUM(A.conqty) AS conqty

FROM gcos_TEGCIFLabNoBOM AS A WITH(NOLOCK)

WHERE A.labno = '241203-009SU061227A'

AND Master_IDX_No \<\> 1665

-- 원료함량 집계

SELECT SUM(A.conqty) AS conqty

FROM gcos_TEGCIFLabNoBOM AS A WITH(NOLOCK)

WHERE A.labno = '241203-009SU061227A'

AND IFYn IS NOT NULL

 

 

--=========================================================================================

--=========================================================================================

-- 연구개발노트세부정보조회(이젬코)\_gcos

SELECT A.phase AS phase

, A.sub_phase AS sub_phase

, A.itemcode AS itemcode

, A.conqty AS conqty

, CASE WHEN ISNULL(A.Results,'') = '' THEN '0' ELSE '1' END AS IsIF

FROM gcos_TEGCIFLabNoRSRC AS A WITH(NOLOCK)

WHERE A.labno = '241203-009SU061227A'

ORDER BY A.phase, A.itemcode -- 20230109 by ghpark 우측 상단시트 조회에 대한 정렬 구문 추가하였습니다.

 

 

SELECT \* FROM gcos_TEGCIFLabNoRSRC AS A WITH(NOLOCK) WHERE A.labno = '241203-009SU061227A'

안녕하세요. 개발팀 박성재 입니다.

1\. 최초에 Master_IDX_No = 1665 (37건)에 대해 BOM 생성

 

2\. 2건에 대해서 상구분을 변경 =\> 1754 (37건)

상구분 변경된 2건에 대해서는 1665가 그대로 남아있고,

 

이미 BOM생성된 건에 대해서 재전송한 데이터가 수정 2건은 인터페이스 유무가 NULL로 저장되었습니다.

 

\[벌크BOM처리(이젬코)\_gcos\] 화면에서 하위품목 조회 시

1\. 'Master_IDX_No' MAX 건 (Master_IDX_No = 1665 2건 제외)

2\. BOM등록된 건의 경우 인터페이스 유무가 NULL 아닌 건 조회(수정된 2건 제외)

총 35건 조회하고 있습니다.

﻿

\[본처방세부정보조회(이젬코)\_gcos\] 에서는 인터페이스유무 NULL 2건 + Master_IDX_No = 1665 이 같이 조회되어 39건 조회되고 있습니다.

﻿

이미 BOM 생성된 건에 대해 데이터가 수정되어 발생한 오류로 사료됩니다.

확인 부탁 드립니다.
