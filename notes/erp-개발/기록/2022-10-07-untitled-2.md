# 

\- 일자별판매실적분석 화면에서 출력합니다.        

\- 조회조건에 해당하는 판매내역을 일자별로 출력합니다. <span class="mark">출고일자별 페이지 넘김.</span>        

\- 순번 : 출고일자의 거래처별 수주/거래명세서/세금계산서 번호기준의 순번을 조회합니다.        

\- 수량 :        

        (기존) 판매수량 \* 실적조회시중량(품목분류4의 Item1값)

        (변경) <span class="mark">품목의 추가정보에 실적단위중량(Kg) 항목 추가</span>. 판매수량 \* 실적단위중량(Kg). 실적단위중량 0 또는 없으면 판매수량 출력.

\- 단가 :        

        (기존) 판매단가 / 실적조회시중량(품목분류4의 Item1값)

        (변경) 품목의 추가정보에 실적단위중량(Kg) 항목 추가. 판매단가 / 실적단위중량(Kg). 실적단위중량 0 또는 없으면 판매수량 출력.

\- 비고 : 마스터 비고. 동일한 번호 칸합치기.        

\- 합계 : 거래처별 수량, 금액, 부가세포함가 합계 조회.        

\- 일계 : 일자별 수량, 금액, 부가세포함가 합계 조회.        

\- 총계 : 전체 조회기간의 수량, 금액, 부가세포함가 합계 조회.        

\- 선모양, 굵기 등 기존과 동일하게 구성해 주세요.        

\- 대화페인트공업(주) 명칭 왼쪽 출고일자와 맞게 정렬 해주세요.
