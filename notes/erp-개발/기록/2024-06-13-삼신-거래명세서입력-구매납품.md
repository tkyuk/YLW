# 삼신 - 거래명세서입력 - 구매납품

안녕하세요. 개발팀 박성재 입니다.

 

1\. 본사 (삼신)에서 거래명세서 저장 시 MCO연동 테이블에 데이터 생성됩니다. 진행여부 컬럼 (IsProg = '0')

2\. 계열사 (삼신밸브) \[본사출고조회_ssv\] 화면에서 해당 건 조회 후 \[구매납품입력_ssv\] 화면으로 점프합니다.

3\. 진행완료 후 연동테이블의 진행여부 컬럼 (IsProg) '1'로 업데이트 됩니다.

4\. 출고 취소 시 계열사 구매납품 진행된 건 (진행여부 컬럼 (IsProg)  '1')은 취소 통제되어있습니다.

\- 거래명세서 품목조회의 진행 상태의 경우 계열사의 진행이 아닌, 세금계산서 진행으로 계열사 진행과 별개의 데이터 조회하고 있습니다.

확인 부탁 드립니다.

 

감사합니다.

 

| 본사 | 삼신 | 거래명세서입력 | 출고하면 연동테이블 데이터 생성 ssv_TSLInvoiceItemMCO |
|----|----|----|----|
| 계열사 | ex. 밸브 | 본사출고조회_ssv | 수주번호, 품목을 통해 본사에서 생성한 데이터 조회 후 납품 생성 |
| 본사 | 삼신 | 거래명세서입력 | 계열사에서 납품생성 시 진행여부 컬럼 '1' 로 업데이트 |
