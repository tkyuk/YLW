# 그룹웨어 결재상신에 이상한 데이터 출력

![](assets/그룹웨어-결재상신에-이상한-데이터-출력/image74.png)

 

\_TCOMEnvGroupWare 테이블의 body에 저 값이 들어가 있었음

환경설정 - 그룹웨어 에서도 값 확인이 가능함

 

UPDATE \_TCOMEnvGroupWare

SET Body = REPLACE(Body,'YLW22#','')

FROM \_TCOMEnvGroupWare
