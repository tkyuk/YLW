# 5/9 같은 속성 선택되었을 때만 점프

참고화면

발주내역조회(SCM)\_amt =\> 납품요청입력(SCM)\_amt ==\> 같은 거래처가 선택되었을 때만 점프

-- 구매처가 다른 건이 선택되었을 때 점프 안되게 에러처리

local CustSeq, DiffCustSeq, chkCust

 

CustSeq = GetDataSetValue(m_SendXml.Data, 'DataBlock1', 'CustSeq', 0)

 

for row = 0, GetDataBlock(m_SendXml.Data, 'DataBlock1').Rows.Count - 1 do

> DiffCustSeq = GetDataSetValue(m_SendXml.Data, 'DataBlock1', 'CustSeq', row)
>
>  
>
> if CustSeq ~= DiffCustSeq then
>
> chkCust = 1
>
> end

end

 

if chkCust == 1 then

> msg1 = GetMessage('1122', GetDictionary(6), '', '', '', '', '', '', '', '', '' )
>
> msgType = MessageBox(msg1, '', 'MsgBoxTypeOK')
>
> \_base.IsJumpEventCancel = true
>
> GoTo('END')
>
> return

end

 

 

입고 버튼 눌렀을 때 =\> 출고가 있으면 안됨

입출고내역조회_gcos =\> 하이랙입고입력 or 하이랙출고입력
