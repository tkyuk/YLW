# 단가, 외화, 원화 소수점

판매반품입력_mcnv

 

 

환경설정(개발자) - (운영공통) - 15번 에 설정이 되어있음

(운영공통)

원화 =\> 소수점 0자리

외화 =\> 소수점 4자리

 

따라서 Declength를 쓰는게 아니라

default 값에 밑에 값을 넣기만 하면 된다

 

ENV_DecLenFOR =\> 외화

ENV_DecLenKOR =\> 원화

 

베트남 화면의 경우 베트남이 원화이므로

바꿔써야한다
