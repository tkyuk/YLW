# VBScript: SetControlInfo / Specified cast is not valid.

녹수 - 수출BL입력\*

VBScript: SetControlInfo / Specified cast is not

valid.

 

**※ 요청사항**

**\[수출BL입력\*\] 화면으로 점프하게 되면 첨부 이미지의 오류가 발생합니다.**

**오류 확인 부탁드립니다.**

**또한 \[수출BL입력\*\] 화면에서 신규 저장하려고 해도 "사업장" 부분이**

**기재되지 않으며 신규 버튼 클릭 시**

**Object reference not set to an instance of an object. 오류가 발생합니다.**

 

 폼등록 \> 폼세부조회의 컨트롤 데이터가 화면의 데이터와 맞지 않아 발생한 오류로 확인하였습니다.

데이터 삭제 후 재생성하여 처리하였습니다.
