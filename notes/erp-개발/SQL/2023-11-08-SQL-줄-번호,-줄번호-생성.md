# SQL 줄 번호, 줄번호 생성

1.  도구 메뉴에서 옵션 을 클릭합니다.

2.  텍스트 편집기를 클릭합니다.

3.  모든 언어를 클릭합니다.

4.  일반을 클릭합니다.

5.  **줄 번호**를 선택합니다.
