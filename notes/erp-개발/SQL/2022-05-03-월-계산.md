# 월 계산

취득월로부터 2017년 12월까지의 월수(2018년 이후 취득시에는 0)

CASE WHEN Asst.GainDate \> '20171231'

> THEN 0

ELSE DATEDIFF(month, LEFT(Asst.GainDate,6)+'01','20220101')

 

END,

 

 

취득일과 2018년 1월 1일 중 더 늦은 일자와 내용년수로 자동계산

CONVERT(NCHAR(6), DATEADD(M, A.AsstYearKOR - 1, CASE WHEN Asst.GainDate \> '20180101' THEN Asst.GainDate ELSE '20180101' END),112)
