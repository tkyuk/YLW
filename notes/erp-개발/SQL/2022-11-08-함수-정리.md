SELECT subject, \[1반\],\[2반\],\[3반\]

-- 가져올 컬럼명 열로 변환시킬 행

 

FROM (SELECT class,subject,score FROM \#examresult) AS EXAM

-- 테이블

PIVOT (

AVG(score)

-- 집계 함수(검색할 열)

FOR class

-- 크로스탭의 기준이 되는열

IN (\[1반\],\[2반\],\[3반\])

-- 변환시킬 행

) AS PIVOTTABLE1

-- 피벗 테이블의 별칭

 

-- 반 별로 과목 점수 출력

SELECT class, \[국어\],\[수학\],\[과학\]

FROM (SELECT class,subject, score FROM \#examresult) AS \#EXAM

PIVOT (

AVG(SCORE)

 

FOR SUBJECT

IN (\[국어\],\[과학\],\[수학\])

) AS PivotTable

**✅ IDENT_CURRENT vs 다른 IDENTITY 관련 함수 비교**

| **함수** | **설명** | **트리거 영향** | **세션 영향** |
|----|----|----|----|
| IDENT_CURRENT('테이블') | **특정 테이블에서 가장 최근 생성된 ID** | ✅ 트리거 영향 받음 | ❌ 세션 상관없음 |
| SCOPE_IDENTITY() | **현재 세션에서 가장 마지막으로 생성된 ID** | ❌ 트리거 영향 없음 | ✅ 현재 세션에서만 동작 |
| @@IDENTITY | **현재 세션에서 가장 최근 생성된 ID (트리거 포함)** | ✅ 트리거 영향 받음 | ✅ 현재 세션에서만 동작 |
