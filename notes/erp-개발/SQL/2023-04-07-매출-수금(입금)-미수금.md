# 매출 수금(입금) 미수금

SELECT \* FROM \_TSLBillCreditSum -- 세금계산서 월별 집계

SELECT \* FROM \_TSLCreditSum -- 거래명세서 월별 집계

 

\_TSLBillCreditDaily

\_TSLCreditDaily

 

 

SumType In (0, 1, 2) -- 0:이월, 1:채권, 2:수금

 

22년 SumType = 0 =\> 21년 이월 금액

> =\> 근데 이월데이터가 없을수도 있음
>
> =\> 21년 1데이터 - 2데이터 으로 22년 이월 미수금 구할 수 있다
>
>  

수주입력 -\> 거래처 입력 후 '여신조회' 클릭 하면 미수금 조회 가능

>  

\-  **이월 미수금** (전년도 매출액 - 전년도 수금액)

\-  **매출액** (당해년도 매출액)

\-  **수금액** (당해년도 수금액)

\-  **미수금** (2. 이월 미수금 + 3. 매출액 - 4. 수금액)
