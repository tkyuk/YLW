# 서버 '\~\~~'이(가) RPC에 대해 구성되지 않았습니다.

1.  DB서버에서 사용할 수 있는 서버 조회

    1.  exec sp_helpserver

>  

2.  status에 rpc, rpc out 항목 미존재 -\> RPC, RPC OUT 활성화하기

    1.  EXEC sp_serveroption '연결된서버IP주소', 'RPC', TRUE

    2.  EXEC sp_serveroption '연결된서버IP주소', 'RPC OUT', TRUE

 

ex.

EXEC sp_serveroption 'SHMC', 'RPC', TRUE

EXEC sp_serveroption 'SHMC', 'RPC OUT', TRUE
