# 최대값 가진 Row추출

2\. Self Left Join 을 이용한 쿼리

SELECTa.id, a.rev, a.contents\
FROMYourTable a\
INNERJOIN(\
SELECTid, MAX(rev) rev\
FROMYourTable\
GROUPBYid) b ONa.id = b.id ANDa.rev = b.rev

Group By 키워드를 사용하지 않고 Self Left Join을 통해 최대값을 찾는 쿼리이다.

\`b.rev\`가 NULL 이라면 \`a.rev\`가 최대값이기 때문에 최대값을 가진 row값을 추출을 할수가 있다.

 

출처: \<<https://overcode.tistory.com/entry/%EC%B5%9C%EB%8C%80%EA%B0%92%EC%9D%84-%EA%B0%80%EC%A7%84-Row-%EB%93%A4%EC%9D%84-%EC%B6%94%EC%B6%9C%ED%95%98%EB%8A%94-SQL-%EC%BF%BC%EB%A6%AC-2%EA%B0%80%EC%A7%80-Group-By-MAX>\>

 

 

SELECT \*

FROM MCNK_TWACLoanFund AS A

INNER JOIN (

SELECT CompanySeq, LoanFundSeq, MAX(Serl) AS Serl

FROM MCNK_TWACLoanFund

GROUP BY CompanySeq, LoanFundSeq

)

AS B ON A.CompanySeq = B.CompanySeq

AND A.LoanFundSeq = B.LoanFundSeq

AND A.Serl = B.Serl

1\. Group By 와 MAX 를 이용한 쿼리

SELECTa.id, a.rev, a.contents\
FROMYourTable a\
INNERJOIN(\
SELECTid, MAX(rev) rev\
FROMYourTable\
GROUPBYid) b ONa.id = b.id ANDa.rev = b.rev

Group BY와 SubQuery를 활용하여 먼저 id와 max값을 가지고 온뒤 INNER JOIN을 이용하여 해당하는 ROW를 찾아오는 쿼리이다.

group by 특성상 해당하는 row의 다른 필드의 값을 가지고 올수가 없다.

 

출처: \<<https://overcode.tistory.com/entry/%EC%B5%9C%EB%8C%80%EA%B0%92%EC%9D%84-%EA%B0%80%EC%A7%84-Row-%EB%93%A4%EC%9D%84-%EC%B6%94%EC%B6%9C%ED%95%98%EB%8A%94-SQL-%EC%BF%BC%EB%A6%AC-2%EA%B0%80%EC%A7%80-Group-By-MAX>\>

 

SELECT a.id, a.rev, a.contents FROM YourTable a INNER JOIN ( SELECT id, MAX(rev) rev FROM YourTable GROUP BY id ) b ON a.id = b.id AND a.rev = b.rev

CREATE TABLE \#TMP_LOTNo(

ItemSeq INT

,Dummy5 NVARCHAR(100)

)

INSERT INTO \#TMP_LOTNo(ItemSeq,Dummy5)

SELECT B.ItemSeq, MAX(Z.Dummy5)

FROM (

SELECT ItemSeq, MAX(RegDate) AS MaxRegDate

FROM \_TLGLotMaster AS A

WHERE ISNULL(A.Dummy5,'') \<\> ''

GROUP BY ItemSeq

) AS B

LEFT OUTER JOIN \_TLGLotMaster AS Z ON B.ItemSeq = Z.ItemSeq AND Z.RegDate = B.MaxRegDate

GROUP BY B.ItemSeq

ORDER BY B.ItemSeq
