# 서비스요청 테이블 (비공개 설정)

안녕하세요. 운영팀 박연입니다.

 

조인셋에서 인사/급여 모듈로 올린 서비스요청건 전체 다 비공개로 설정 요청드립니다.

 

확인 부탁드립니다.

감사합니다.

 

UPDATE sys_TSYSCustReq

SET IsShare = '2' -- 1:공개, 2:비공개

FROM sys_TSYSCustReq

WHERE CustSeq = 557 -- 조인셋

AND UMModule = 1000126002 -- 인사급여
